# 3D 空间线条绘画工具

基于 **Three.js** 的 3D 交互式线条绘制工具，支持多种绘制模式、平面锁定、端点吸附、笔刷效果等功能，直接在浏览器中运行，无需构建工具。

---

## ✨ 功能特性

### 绘制功能
| 功能 | 说明 |
|------|------|
| **随手画** | 自由绘制曲线，连续记录轨迹点 |
| **直线** | 记录首尾两点，实时预览直线效果 |
| **曲线** | 随手画后 CatmullRom 平滑处理 |
| **笔刷** | 在锁定平面上生成半透明墨迹粒子效果 |

### 交互功能
| 功能 | 说明 |
|------|------|
| **端点吸附** | 绘制时自动吸附到已有端点，续画无缝衔接 |
| **悬浮高亮** | 鼠标悬停端点/线条时实时视觉反馈 |
| **撤销/重做** | Ctrl+Z / Ctrl+Y，完整历史记录 |
| **多选上色** | Ctrl+点击端点多选，自动共面检测并填充半透明面 |
| **测量读数** | 实时显示线条长度和俯仰角 |

### 辅助功能
| 功能 | 说明 |
|------|------|
| **辅助多边形** | 右键 Y 轴生成正多边形辅助线，顶点可作为端点吸附 |
| **圆点/圆球节点** | 双击空白生成圆点，Shift+双击生成圆球 |
| **移动端点** | Alt+拖拽圆点/圆球，连线自动跟随 |
| **导入/导出** | 场景数据导出为 JSON，支持重新导入恢复 |
| **编辑/预览模式** | 切换模式控制绘制交互和辅助元素可见性 |

### 平面绘制
| 功能 | 说明 |
|------|------|
| **镜头面** | 投影到正对相机的平面（默认，笔触正对镜头） |
| **水平面** | 投影到水平面 XZ，旋转相机可在不同高度叠层绘制 |
| **地面锁定** | 锁定到地面网格平面 (y=-3) |
| **3点定面** | 依次点击 3 个端点圆球定义任意倾斜平面 |
| **多边形平面** | 选中辅助多边形后，沿 Y 轴与顶点决定的竖直平面绘制 |

## 📖 使用指南

### 基本操作

| 操作 | 效果 |
|------|------|
| **左键拖拽** | 绘制线条 |
| **右键拖拽** | 旋转相机 |
| **中键拖拽** | 平移视图 |
| **滚轮** | 缩放 |

### 绘制模式切换

| 按键 | 模式 | 说明 |
|------|------|------|
| `1` | 随手画 | 自由绘制曲线 |
| `2` | 直线 | 绘制直线段 |
| `3` | 曲线 | 绘制平滑曲线 |

### 模式切换

| 按键 | 功能 |
|------|------|
| `E` | 进入编辑模式（可绘制） |
| `P` | 进入预览模式（仅查看） |
| `Esc` | 取消当前操作 / 清除选中 |

### 端点与节点操作

| 操作 | 效果 |
|------|------|
| **点击端点** | 高亮选中端点 |
| **点击端点后拖拽** | 从该端点续画 |
| **双击端点** | 聚焦相机到该端点 |
| **双击空白** | 生成小圆点（可作为连线节点） |
| **Shift+双击空白** | 生成大圆球（可作为连线节点） |
| **Alt+拖拽端点** | 移动端点位置，连线自动跟随 |
| **右键端点/圆球** | 删除该节点 |
| **Ctrl+点击端点** | 多选端点（用于上色面） |

### 辅助多边形

| 操作 | 效果 |
|------|------|
| **右键 Y 轴（绿色）** | 弹出弹窗，输入半径和边数生成辅助多边形 |
| **点击辅助多边形** | 选中该多边形，顶点可作为端点吸附 |
| **Delete 选中多边形** | 删除选中的辅助多边形 |

### 平面绘制

1. **镜头面/水平面**：在左上角面板选择"镜头面"或"水平面"，然后直接绘制
2. **地面锁定**：点击"地面"按钮，锁定到 y=-3 平面绘制
3. **3点定面**：
   - 点击"3点定面"按钮进入拾取模式
   - 依次点击 3 个端点圆球定义平面
   - 平面锁定后，后续绘制都在该平面上
   - 按 Esc 或点击"解锁"退出
4. **多边形平面**：
   - 选中辅助多边形后，点击"锁定平面"按钮
   - 使用 ◀ ▶ 按钮切换到其他顶点决定的平面

### 线条操作

| 操作 | 效果 |
|------|------|
| **点击线条** | 选中线条，显示长度和俯仰角 |
| **Delete 选中线条** | 删除选中的线条 |
| **清空按钮** | 清空所有绘制的线条（保留辅助元素） |

### 撤销/重做

| 按键 | 功能 |
|------|------|
| `Ctrl+Z` | 撤销上一步操作 |
| `Ctrl+Y` | 重做被撤销的操作 |

### 导入/导出

1. **导出**：点击工具栏"导出"按钮，保存场景为 JSON 文件
2. **导入**：点击"导入"按钮，选择之前导出的 JSON 文件恢复场景

### 颜色与线宽

- 点击工具栏颜色色块切换颜色，或使用颜色选择器
- 拖动"线宽"滑块调整线条粗细（1-20）
- 拖动"球径"滑块调整圆球大小（0.05-0.6）

## 📁 项目结构

```
3D Drawing/
├── index.html              # 主页面入口
├── style.css               # 样式表
└── js/
    ├── main.js             # 主入口：场景初始化、交互逻辑、工具栏绑定
    ├── SceneSetup.js       # Three.js 场景、相机、灯光、辅助元素设置
    ├── LineManager.js      # 线条管理：创建/删除/序列化、端点注册、吸附检测
    ├── DrawingController.js# 鼠标交互控制器：状态机、射线检测、投影平面
    └── BrushManager.js     # 笔刷系统：墨迹粒子生成、淡出、生命周期管理
```
